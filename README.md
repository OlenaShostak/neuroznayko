# НейроЗнайко / НейроЗнайка / NeuroWhizKid / Neuroznajko

Ігровий експрес-скринінг пізнавальних процесів дітей 3–6 років (увага, пам'ять, мислення, сприймання) з анкетою для батьків.
Розроблено в межах наукового дослідження на базі ОНУ імені І. І. Мечникова.

Одразу після проходження батьки отримують звіт з орієнтовною оцінкою пізнавальних процесів дитини, рекомендаціями та віковими орієнтирами розвитку.
Після повторного проходження відкривається другий етап: Банк ігор Мудрої Сови для розвитку пізнавальних функцій і чек-лист сенситивних періодів розвитку мозку дитини з порадами, як найкраще підтримати дитину на кожному з них.

- **Застосунок:** `index.html` — українською, російською, англійською та польською мовами.
- **Банк ігор Мудрої Сови:** `bank.html` — тими самими чотирма мовами.

Ім'я дитини, дата народження та email залишаються лише на пристрої користувача.
Знеособлені результати (код сесії, вік у місяцях, відповіді на завдання й анкету, тип пристрою) надсилаються до захищеної таблиці дослідниці.
Результат має орієнтовний характер і не є діагнозом.
